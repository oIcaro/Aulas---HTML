# Aulas - HTML

Repositório com exercícios práticos de HTML5, desenvolvidos durante um curso em vídeo. Cada pasta (`ex001`, `ex002`, ...) corresponde a uma aula e foca em um conceito específico da linguagem, do básico ao uso de mídias.

## Tecnologias

- HTML5
- CSS (uso pontual, em exemplos específicos)

## Exercícios

| Pasta | Tema | Conceitos praticados |
|---|---|---|
| [`ex001`](./ex001) | Meu primeiro exercício | Estrutura básica de um documento HTML (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`) |
| [`ex002`](./ex002) | Parágrafos | Parágrafos, quebras de linha e símbolos especiais |
| [`ex003`](./ex003) | Teste com imagem | Diferentes formas de carregar imagens (`<img>`, caminhos relativos) |
| [`ex004`](./ex004) | Teste de favicon | Configuração de favicon com `<link rel="shortcut icon">` |
| [`ex005`](./ex005) | Hierarquia de títulos | Semântica e hierarquia de `<h1>` a `<h6>` |
| [`ex006`](./ex006) | HTML4 vs HTML5 | Comparação entre tags obsoletas do HTML4 e a semântica do HTML5 |
| [`ex007`](./ex007) | Formatação de textos | Tags de destaque como `<mark>`, `<strong>`, `<em>`, com estilização via CSS |
| [`ex007b`](./ex007b) | Outras formatações | Código-fonte e pré-formatação (`<code>`, `<pre>`) |
| [`ex008`](./ex008) | Listas | Listas ordenadas e não ordenadas, sublistas, atributos `type` e `start` |
| [`ex009`](./ex009) | Trabalhando com itens | Links externos e internos, navegação entre múltiplas páginas |
| [`ex010`](./ex010) | Mídias em HTML5 | Imagem responsiva (`<picture>`) e reprodução de áudio (`<audio>`) |

## Como visualizar

Clone o repositório:

```bash
git clone https://github.com/oIcaro/Aulas---HTML.git
```

Em seguida, abra o arquivo `index.html` da pasta do exercício desejado diretamente no navegador.
